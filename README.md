# בוחר המשרות

כלי סטטי בעברית (ימין לשמאל) להשוואה ולדירוג של 211 משרות ההשמה מאתר [בוגרים לשלטון המקומי](https://www.bogrim-muni.com/jobs). האתר לא מפעיל את אתר המקור, לא מעתיק את הסמל או את העיצוב שלו, ואין בו שרת משלנו.

הדירוגים, ההערות, יומן השיחות, הכתובת והמסלולים נשמרים רק ב-`localStorage` של הדפדפן, במפתח `bogrim-jobs.v1`. קטלוג המשרות לא נשמר שם.

## בנייה והרצה

```bash
python3 build.py
python3 -m http.server -d dist 8000
```

ואז לפתוח `http://127.0.0.1:8000/`. צריך שרת מקומי: המודולים לא רצים מ-`file://`.

הבנייה קוראת את `data/raw/bogrim_jobs.json` אם הוא קיים במחשב (התיקייה ב-`.gitignore`), אחרת את `data/jobs.json` המסונן שבמאגר. הפלט הציבורי הוא `dist/` וגם רענון של `data/jobs.json`.

## בדיקות

```bash
bash scripts/test.sh
```

הפקודה מתקינה את Playwright הממוסמר (`requirements.txt`), בונה את האתר הציבורי, מריצה בדיקות יחידה על הניקוי והרשימה המותרת, ואז בדיקות דפדפן מול `dist/`. סריקת הדוא״ל והטלפון רצה על הבנייה הזאת — ברירת המחדל, בלי אנשי קשר.

## דגל אנשי קשר

```bash
python3 build.py --include-contacts
```

כברירת מחדל הדגל **כבוי**. בכיבוי:

- שדות אישיים לא נכתבים ל-`dist/` ולא ל-`data/jobs.json`
- הרשימה המותרת חלה, ואין בממשק קישורי `tel:` או `mailto:`
- ממשק אנשי הקשר במגירה קיים בקוד, אבל הוא לא מצויר

בהדלקה, הבנייה קוראת את קובץ ה-JSON הגולמי המקומי (שלא במאגר) וכותבת אל `dist-contacts/` — תיקייה ב-`.gitignore`. היא מסרבת לכתוב לתוך `dist/`. מה שנכנס ל-git לא מכיל אנשי קשר. תיקוני טלפון שהוקלד בשדה דוא״ל, ותיקון סיומת דומיין ידועה, חלים רק על הנתיב הזה.

כפתור המקור במגירה הוא «למודעה המקורית», כי כך קובע `ACCEPTANCE.md`. ניסוח חלופי («לפרטי קשר באתר המקור») לא בשימוש כל עוד רשימת הקבלה מגדירה אחרת.

## מה יש באתר

- קריטריונים עם משקל, סדר, וסוגים: דירוג 1–5, כן/לא, טקסט (בלי ציון), נסיעה אוטומטית. ברירת המחדל: התפקיד והאנשים, מרחק מהבית, תנאים, המלצות, בוגרים אחרים.
- ציון הוא ממוצע משוקלל של מה שדורג. קריטריון בלי דירוג לא נספר כאפס, ומוצג «חלקי».
- כתובת בית מאותרת רק אחרי «אתר כתובת». יישוב מהרשימה המקומית לא יוצא לרשת. אחרת נשלחת בקשה אחת ל-Nominatim.
- זמני רכב, אופניים והליכה רק אחרי «חשב זמני נסיעה» ואישור. בלי מסלול מוצג «קו אווירי (הערכה)».
- מפה (Leaflet מקומי) נטענת רק בלשונית «מפה», ואז גם אריחי OpenStreetMap.
- השוואה של עד 4 משרות, ייצוא JSON ו-CSV, ייבוא JSON, ו«נקה נתונים».

## פרטיות ומבנה

`robots.txt` חוסם את כל האתר, וב-HTML יש `noindex`. מדיניות אבטחת התוכן אוסרת סקריפטים ועיצוב חיצוניים. בטעינה אין בקשות לצד שלישי.

| נתיב | תפקיד |
| --- | --- |
| `src/` | המקור של הדפים |
| `dist/` | האתר הבנוי, בלי אנשי קשר |
| `data/jobs.json` | הקטלוג המסונן שנשמר במאגר |
| `data/raw/` | סריקה גולמית, לא במאגר |
| `dist-contacts/` | בנייה מקומית עם אנשי קשר, לא במאגר |
| `geo/` | קואורדינטות רשויות ורשימת יישובים |
| `vendor/leaflet/` | Leaflet 1.9.4, בלי CDN |
